# Rohdokumente

Alle Dokumente in diesem Ordner sind **fiktiv** und dienen nur der Übung. Die Muster Maschinenbau GmbH ist dasselbe Lehrbeispiel wie in LE 4.

Regeln: Menschen legen hier Dateien ab. Der Agent liest sie, verändert sie aber nie. Die Pipeline schlägt fehl, wenn eine Datei in `raw/` geändert oder gelöscht wird.

Eigene Dokumente dürft ihr ergänzen – aber nur solche, die ihr ohne Bedenken an einen externen Dienst geben dürftet (siehe LE 2: Datenschutz je Nutzungsform).
